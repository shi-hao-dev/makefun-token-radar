Token Launch Radar — ranks 198 pre-token protocols by implied value (TVL × a category multiple derived from live-token comparables in the same snapshot × 7-day growth × maturity × chain breadth), with a concrete farm plan for each, on a sealed DefiLlama snapshot. The dashboard is a static, offline page: a sortable, filterable board, a detail view per protocol with the value breakdown, the live-token comparables behind the multiples, and a model sandbox that re-ranks the board live.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
