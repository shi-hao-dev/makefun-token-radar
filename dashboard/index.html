How the value is worked out

Every protocol on the board records no token. Its implied value is not a multiple anyone chose: it is a least-squares fit on the 128 live-token protocols in this snapshot, re-fitted from the snapshot's own figures every time the page is built:

ln(mcap) = … + … × ln(TVL) + … × growth + … × age_years
implied = exp(ln(mcap)), rounded to a whole dollar, at least $1

growth is the 7-day TVL change clamped to −50%…+100% (unreported counts as 0); age_years is the days from first listing to the snapshot date over 365 (unknown counts as 1 year). Fit quality: R² = … on log market cap, n = 128 live tokens. The board covers all 40 watchlist protocols plus 158 more pre-token protocols below the floor that pass the same exclusions — the whole eligible universe, not a capped top-N.

Validation — the fit, checked against the old median-multiple model

Both models are scored on the same held-out protocols, on the log scale (lower is better). The fitted model wins every split, so it is the one the board uses.
