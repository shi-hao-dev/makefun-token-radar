How the value is worked out

Every protocol on the board records no token. Its implied value is its TVL times a multiple, times a growth factor, times a maturity factor, times a chain factor:

implied = TVL × multiple × (1 + clamp(7d change, −50%, 100%) × 0.5) × (0.6 + min(age, 1095d) / 1095 × 0.4) × (1 + 0.02 × min(chains − 1, 5))

The multiple is not a flat number: it is the median market-cap-to-TVL ratio of the live-token protocols in the same category, computed from this snapshot (see ). Categories with fewer than 3 live tokens use the all-category median. Nothing is ranked by name — the same function scores every row. The board covers all 40 watchlist protocols plus 158 more pre-token protocols below the floor that pass the same exclusions.
